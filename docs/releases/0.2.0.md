# Big Bang 0.2.0

## 简体中文

- 编辑输入后可“返回结果”，恢复此前的结果、阅读位置、文字选区和键盘焦点；保留你随后切换到其他窗口的焦点选择。
- 改善 Markdown 回退显示中的选区保留，内容或外观更新时仍能继续选择和复制文字。
- 停止生成后在标题栏显示“已停止”。阅读长结果时也能看到失败提示，点击即可定位详情；输出变化时清除过期的“已复制”反馈。
- 改进跨应用及截图预览“实况文本”的选区读取，跟随实际键盘焦点；更稳妥地处理复制回退和焦点变化，避免误用旧选区或覆盖新的剪贴板内容。
- 方向键、功能键等特殊快捷键显示可读名称和符号；菜单栏图标的悬停提示同步当前预设名称和快捷键。
- 恢复默认预设后仍可撤销删除，找回自定义内容、原快捷键和位置。恢复项已编辑或原快捷键被占用时，撤销会提示冲突并保留当前预设；保存失败可重试。恢复预设也不会中断待保存输入的自动保存。

支持 macOS 14 及以上版本；Universal 应用包含 Apple Silicon（arm64）和 Intel（x86_64）。

## English

- Choose **Back to Result** after editing input to restore the previous result, reading position, text selection, and keyboard focus. A later focus change to another window is respected.
- Preserve text selections more reliably in the Markdown fallback display, so content or appearance updates still allow you to select and copy text.
- Show **Stopped** in the header after stopping generation. Failures remain visible while reading long results, with a click to reach the details; changes to the output clear stale **Copied** feedback.
- Improve selection capture across apps and in screenshot-preview **Live Text** by following actual keyboard focus. Handle copy fallback and focus changes more reliably to avoid using stale selections or overwriting newer clipboard content.
- Display readable names and symbols for special shortcut keys, including arrow and function keys. The menu bar icon’s tooltip reflects current preset names and shortcuts.
- Undo a deletion even after restoring default presets to recover custom content, the original shortcut, and list position. If a restored preset has been edited or its original shortcut is in use, Undo explains the conflict and preserves the current presets; failed saves can be retried. Restoring presets also keeps pending input autosaves running.

Requires macOS 14 or later. The Universal app includes Apple Silicon (arm64) and Intel (x86_64).
