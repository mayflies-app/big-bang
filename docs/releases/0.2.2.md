# Big Bang 0.2.2

## 简体中文

- 在「设置 → 处理预设」中，可为每项预设单独开启直接输入。开启后，按快捷键会跳过选区读取并聚焦空白便签的输入框，提交后开始处理。
- 内建助手预设默认开启直接输入，其余预设默认关闭。

支持 macOS 14 及以上版本。Universal 应用包含 Apple Silicon（arm64）和 Intel（x86_64）。

## English

- Turn on Direct Input for any preset in Settings → Presets. Its shortcut skips selection capture and focuses the input field in a blank note. Processing starts when you submit your text.
- Direct Input is on by default for the built-in Assistant preset and off for other presets.

Requires macOS 14 or later. The Universal app includes Apple Silicon (arm64) and Intel (x86_64).
